# Report Directory

This directory will contain the final project report (PDF) upon submission.

**Expected file:** `RoadSense_Group4_Final_Report.pdf`

The report covers all 6 phases of the RoadSense project following the capstone brief outline (Section 8):
1. Title page, group members & public GitHub link
2. Abstract (150-200 words)
3. Introduction and motivation
4. Related work
5. Dataset: source, classes, splits, EDA findings, preprocessing
6. Methodology: architectures, loss, optimiser, hyper-parameters, augmentation
7. Experiments and results: tables and plots for every model, with honest comparison
8. Error analysis and explainability (Grad-CAM, misclassified samples)
9. Limitations, ethics and future work
10. Conclusion
11. Contribution table and references
